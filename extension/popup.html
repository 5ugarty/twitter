트윗 아카이버 설정

gist 권한이 있는 GitHub 토큰과, 데이터를 저장할 Gist ID를 입력하세요.

여기 등록한 계정의 트윗은 자동추가든 수동추가든 항상 그 아이디 이름 폴더로 분류돼요.
"폴더명: 계정1, 계정2" 형식으로 입력하세요.
내 계정이 아닌 남의 계정이라도, 여기 등록해두면 수동추가("＋") 시 해당 폴더로 자동 분류돼요.
예: 엄껀: A, B, C → A/B/C 계정 트윗을 수동추가하면 자동으로 "엄껀" 폴더에 들어감.
Gist에 있는 트윗 목록을 다시 불러와서, 트위터에서 이미 저장된 트윗에 ✓ 표시가 뜨도록 캐시를 최신화해요. 웹앱에서 직접 삭제/수정했을 때 눌러주면 좋아요.
